# onlyice/homebrew-tap

Homebrew tap for my macOS apps.

## Usage

```bash
brew install --cask onlyice/tap/agent-sessions
```

Upgrading:

```bash
brew upgrade --cask agent-sessions
```

## Casks

| Cask | Description |
| --- | --- |
| [agent-sessions](https://github.com/onlyice/agent-sessions) | Browse, search and resume coding agent sessions (Claude Code, Codex, OpenCode, Pi, Amp) |

The cask is bumped automatically by the release workflow in
[onlyice/agent-sessions](https://github.com/onlyice/agent-sessions) whenever a
`v*` tag is pushed.
